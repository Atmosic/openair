# MCUboot Multiple Key Support Test

This test verifies the MCUboot multiple key support feature.

## Overview

This test demonstrates that MCUboot can verify images signed with any of multiple configured keys. This is useful for:
- Key rotation scenarios
- Supporting images from multiple sources
- Gradual migration from one key to another

## Test Structure

The test creates:
- Primary application: Signed with `test-key-1.pem`
- Swapped application: Signed with `test-key-2.pem`

MCUboot is configured with both public keys and should be able to verify and boot applications signed with either key.

## Configuration

The test uses the following configuration files:

### Sysbuild Configuration (`sysbuild.conf`)
- `SB_CONFIG_BOOTLOADER_MCUBOOT=y`: Enable MCUboot bootloader
- `SB_CONFIG_BOOT_SIGNATURE_TYPE_ECDSA_P256=y`: Use ECDSA P-256 signatures
- `SB_CONFIG_BOOT_MULTIPLE_SIGNATURE_KEYS=y`: Enable multiple key support

### MCUboot Configuration (`sysbuild/mcuboot.conf`)
- `CONFIG_BOOT_MULTIPLE_SIGNATURE_KEYS=y`: Enable multiple key support (supports 2 keys)
- `CONFIG_BOOT_SIGNATURE_KEY_FILE`: Primary key file
- `CONFIG_BOOT_SIGNATURE_KEY_FILE_2`: Second key file

## Running the Test

```bash
west build -b <board> openair/tests/boot/test_mcuboot_multikey --sysbuild
west flash
```

## Expected Behavior

1. MCUboot starts and verifies the primary application (signed with key 1)
2. Application marks secondary slot for swap
3. MCUboot verifies the secondary application (signed with key 2)
4. MCUboot performs the swap
5. The swapped application boots successfully

This demonstrates that MCUboot can verify images signed with any of the configured keys.

## Test Keys

The test keys (`test-key-1.pem` and `test-key-2.pem`) are located in this directory and are automatically generated by the Jenkins pipeline or can be manually generated using:

```bash
cd openair/tests/boot/test_mcuboot_multikey
python3 ../../../../bootloader/mcuboot/scripts/imgtool.py keygen -k test-key-1.pem -t ecdsa-p256
python3 ../../../../bootloader/mcuboot/scripts/imgtool.py keygen -k test-key-2.pem -t ecdsa-p256
```

**Note:** These keys are for testing only and should never be used in production.
